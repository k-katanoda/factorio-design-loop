# 常時昼間の起動電源（候補）

## 前提

- Factorio 2.0 の通常品質・モジュールなし、太陽光出力は常時100%（60 kW/基）。昼夜サイクル、薄明、悪天候や他の電力負荷は対象外。
- 鉄・ウラン鉱床、油田、水辺と、太陽光設置場所は仮定。ブループリントは地形や資源を生成しない。
- 既存設備すべてが同時に定格で動き、全インサータと照明も最大消費するという実際より保守的な上限を使う。炉が発電する前を対象にする。電力消費と待機電力を両方加算する。

## 設置

- 太陽光パネル 200基 × 60 kW = **12 MW**。
- 蓄電池 1基：5 MJ、充放電最大300 kW。常に完全な日射がある前提では連続稼働に蓄電容量は不要だが、指定に合わせて短時間の変動用に設置。夜間を賄う設計ではなく、0.3 MWを超える不足を単独では補えない。
- 変電所6基でパネルと蓄電池を覆い、既存変電所1131へ接続。ウラン鉱石入力インサータ1045の給電範囲外を解消する中型電柱1基を追加。

## 消費電力の保守的上限

| 設備 | 数量 | 稼働＋待機電力の合計上限 |
|---|---:|---:|
| 遠心分離機 | 17 | 約6,148.3 kW |
| 組立機3 | 1 | 387.5 kW |
| 電気炉 | 2 | 372 kW |
| 化学プラント | 2 | 434 kW |
| 製油所 | 1 | 434 kW |
| 電気採掘機 | 4 | 372 kW |
| 油井 | 1 | 93 kW |
| 高速インサータ | 41 | 2,451.8 kW |
| バルクインサータ | 4 | 680 kW |
| ロングインサータ | 8 | 174.4 kW |
| インサータ | 11 | 170.5 kW |
| ランプ・条件回路 | 16・4 | 84 kW |
| **合計** | | **約11,801.5 kW** |

最大想定との差は約198.5 kW。全負荷が同時に継続する仮定でも、蓄電池の充電に余剰が残る。インサータ最大消費は保守的な値（高速59.3 kW、バルク169 kW、ロング21.4 kW、通常15.1 kW）を採用。遠心分離機等の待機電力は稼働電力の1/30で計算した。

## 検証と制限

追加設備の矩形による干渉、パネルと蓄電池の電力範囲、電柱接続、既存の電気消費設備の電柱範囲、12 MWと計算上限を検査した。これはFactorio本体の設置・通電・動作検証ではない。実マップの地形、日射、電力網の復元、鉱石供給、燃料循環、起動までの稼働と充電は **UNKNOWN**。
